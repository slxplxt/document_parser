# Smart Document Parser (Resume Extractor)

Production-ready сервис для структурирования, авто-очистки и валидации данных из резюме с использованием **GigaChat API** и **Pydantic v2**.

## Ключевой функционал

* **Structured Outputs**: Строгое извлечение данных по заданной Pydantic-схеме.
* **Автоматическая очистка и нормализация (Pydantic Validators)**:
  * Телефоны приводятся к единому формату `7XXXXXXXXXX`.
  * Никнеймы Telegram очищаются от `@` и внешнего мусора.
  * Даты мест работы приводятся к ISO-формату (`YYYY-MM`).
* **Бизнес-метрики**: Расчет суммарного стажа кандидата в месяцах и форматирование в человекочитаемую строку с правильным склонением падежей (*"6 лет и 1 месяц"*).
* **Управление конфигурацией**: Загрузка и валидация параметров через `pydantic-settings`.
* **Автотесты**: Покрытие бизнес-логики очистки и расчетов с помощью `pytest`.

## Технологии

* **Python**
* **Pydantic**
* **GigaChat API** (`GigaChat-3-Lightning`)
* **Pytest**
